# Everyday Tools

One-page tools for everyday decisions: comparison tables and calculators, with every number linked to where it came from. Everything runs in the browser; calculators keep their inputs in the page link, not on a server.

Calculators give estimates, not financial, tax or medical advice. Tax rules, card terms and rates change, so each page shows the date its rules were checked.

## Layout

```
everyday-tools/
├── README.md
├── .github/workflows/
│   ├── pages.yml                 # publishes site/ to GitHub Pages on push to main
│   └── refresh-data.yml          # Mondays: re-fetch layoffs + PPP data, commit, republish
├── scripts/                      # data refresh scripts (not published)
│   ├── fetch_warn.py             # Washington WARN notices → site/wa-layoffs/data.json
│   ├── fetch_ppp.py              # World Bank PPP + exchange rates → site/salary-converter/data.json
│   ├── data/currencies.json      # ISO 4217 currency per country, used by fetch_ppp.py
│   └── requirements.txt
└── site/                         # everything that gets published
    ├── index.html                # hub page; the tool list is the JSON block at the bottom
    ├── assets/
    │   ├── theme.css             # shared look, light and dark
    │   ├── site.js               # shared helpers: theme toggle, tabs, share links, paging
    │   └── favicon.svg
    ├── whey-protein/
    │   ├── index.html
    │   ├── app.js                # page logic
    │   ├── scoring.js            # the spreadsheet's scoring formulas, ported to JS
    │   └── data.json             # products (raw label values) + price history
    ├── magnesium/                # index.html, app.js, data.json in each tool folder
    ├── supplements/
    ├── salary-converter/         # data.json is generated by scripts/fetch_ppp.py
    ├── wa-layoffs/               # data.json is generated by scripts/fetch_warn.py
    ├── credit-cards/             # card terms in data.json, with source + date per card
    ├── income-tax/               # tax rules in the RULES constant at the top of app.js
    ├── home-loan/, investing/    # calc.js holds the maths; investing's TAX constant holds fund tax rules
    ├── health-calculators/       # reads the whey, supplements and magnesium data.json files
    └── work-tools/, linkedin-prompt/, unit-converters/, split-bill/
```

No build step and no dependencies. Plain HTML, CSS and ES modules.

## Run locally

```sh
python3 -m http.server 8000 -d site
# then open http://localhost:8000
```

Pages load their `data.json` with `fetch`, so opening the HTML file straight from disk won't work.

## Add a tool

1. Create `site/<tool-name>/index.html`. Copy the header and footer from an existing tool so the theme toggle and share links work.
2. Put the tool's data in `site/<tool-name>/data.json` if it has any.
3. Add an entry to the registry block at the bottom of `site/index.html`. Use `"status": "planned"` to list it as coming soon.
4. Push to `main`. The workflow publishes `site/` within a minute or two.

## Update data

- **Whey:** edit the raw values in `site/whey-protein/data.json` and change `checked` / `checked_label`. Scores and ranks are computed in the browser, so there's nothing else to regenerate. A row is ranked only if its `status` starts with `Live`.
- **Magnesium:** edit `site/magnesium/data.json`. A rating shows as expired automatically once `valid_till_iso` has passed.
- **Supplements:** edit `site/supplements/data.json` and change `as_of`.
- **Layoffs and salary converter:** generated, don't edit by hand. The `Refresh data` workflow runs every Monday, or run it from the Actions tab. Locally:

  ```sh
  pip install -r scripts/requirements.txt
  python3 scripts/fetch_warn.py
  python3 scripts/fetch_ppp.py   # prints any country whose price level looks off; check those
  ```

## Caveats

- These are snapshots, not live feeds. Check the seller before buying.
- Not medical or financial advice.
- Magnesium lab results are summarised from [Unbox Health](https://unboxhealth.in). Supplement scores come from [Limitless Labs](https://limitlesslabs.in) and the review sites listed on that page. Product names belong to their brands.
- Layoff notices: [Washington State Employment Security Department](https://esd.wa.gov/employer-requirements/layoffs-and-employee-notifications/worker-adjustment-and-retraining-notification-warn-layoff-and-closure-database). PPP and exchange rates: [World Bank WDI](https://data.worldbank.org/indicator/PA.NUS.PRVT.PP).
- The salary converter's idea and formula come from [pppconverter](https://github.com/nigelbabu/pppconverter) by Nigel Babu (MIT).
