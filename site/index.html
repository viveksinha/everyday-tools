Comparison tables and small calculators for things we buy and decide on all the time. Numbers come from labels, lab reports and live prices, and every row links back to its source.

How these pages work
  • Each tool is one page with its data in a plain JSON file next to it.
  • Everything runs in your browser. No accounts, no tracking.
What to trust
  • Every page shows the date its prices or lab data were checked.
  • Prices move. Open the seller link before you buy.
Found something wrong?
  • Open an issue on GitHub with the product and the correct number.
